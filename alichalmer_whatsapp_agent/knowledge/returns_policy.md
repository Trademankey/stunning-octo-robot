# Returns Policy

This wholesale bot should not handle retail returns directly. If a user asks for retail order help, damaged items, wrong items, refunds, or returns, capture the last message as a sales handoff or direct the user to a human.

For damaged items, wrong items, or order issues, collect:

- Order number
- Description of the issue
- Photo if the customer can send one
- Email for follow-up

These cases should be escalated to a human after capture.
